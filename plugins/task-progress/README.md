# Task Progress 1.4.0

Устанавливаемый Codex skill-плагин: русская шкала/таблица примерного прогресса, evidence, выбранная область и свежесть. Только локальное чтение явно переданных safe JSON/stdin. Node.js20+, без сторонних зависимостей.

Установка из закреплённого GitHub ref, проверка и откат описаны в [инструкции репозитория](https://github.com/MaximillianVoss/codex-task-progress-plugin/tree/v1.4.0#readme). Если `$task-progress:task-progress` уже доступен, используйте его без повторной установки.

Быстрая проверка из этой папки:

```powershell
node --test tests/core.test.mjs tests/cli.test.mjs tests/html.test.mjs
node skills/task-progress/scripts/render.mjs --input examples/single.safe.json --at 2026-10-21T12:10:00Z
```

Рабочие данные — по [контракту](skills/task-progress/references/contract.md). Если в исходном снимке нет процента и этапов, агент может подготовить примерную оценку по явному плану выбранной задачи и датированным подтверждениям выполненных шагов. Равные веса при отсутствии весов в плане нужно назвать оценочным допущением; без плана процент остаётся неизвестным. Принятый checklist не пересчитывается. Не передавать секреты и переписку. Renderer не открывает evidence автоматически. Через `--format html` одна задача появляется компактным блоком с кругом и линией этапов; полный «Пульт задач» раскрывается по запросу, а для нескольких задач открыт сразу. В полном виде доступны `--view bar|ring`, `--theme night|light|indigo|forest`, `--stages show|hide`. Кнопки вида и тем имеют собственные встроенные значки и подписи; этапы включаются переключателем и раскрываются по строкам, сохраняя evidence. Параметры можно переключать в блоке. Skill показывает HTML в ленте беседы Codex; закрепление над полем ввода не реализовано. Markdown (`--format markdown`) остаётся текстовым форматом по умолчанию. Нет фонового мониторинга и записей в исходную систему.

Сборка: `pwsh -File scripts/Build-Package.ps1`. Локальные READY/CURRENT содержат пути текущей сборки; для передачи используйте только внешний `release.safe.json` из корневого build script. Сборщик не меняет установленный плагин и не подтверждает его discovery.
