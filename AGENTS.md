# Codex Task Progress

Этот репозиторий содержит переносимый skill-плагин и локальный marketplace. Код плагина — `plugins/task-progress`, каталог — `.agents/plugins/marketplace.json`.

- Сохранять offline/read-only границу renderer: читать только явно выбранный safe JSON/stdin, не открывать evidence, не обращаться к Planner, секретам и клиентским данным.
- Прогресс относится к точной выбранной области; unknown не равен 0. Fixed checklist не повышается визуальной оценкой, работа/время не доказывают завершение; 100% требует приёмки.
- Перед сдачей изменений выполнять `npm test`; после изменений упаковки также `pwsh -File scripts/Build-Release.ps1`. Node.js20+; внешних зависимостей нет.
- Не изменять установленный cache, глобальные настройки Codex и другие плагины из задачи разработки этого репозитория. Установка/обновление — отдельная операция, если она нужна текущему поручению.
- Локальные отчёты, snapshots, READY и dist не коммитить. В GitHub Release размещать только собранный ZIP и переносимую квитанцию с SHA256, без локальных путей.
- Сохранять пользовательские модель/уровень рассуждения; Superpowers применять только по явному запросу владельца.

Названия, topics и сохранение исходных метаданных — по [repository-governance](https://github.com/MaximillianVoss/repository-governance).
